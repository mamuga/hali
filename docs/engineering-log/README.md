# Engineering log

This folder holds the actual prompts and plans used to direct AI coding
agents through each layer of HALI's build: database provisioning, the
ingestion ETL, the AI translation ensemble, GIS features, security
hardening, and the demo production pipeline.

They're kept as-run, not cleaned up for presentation, as a record of the
actual development process rather than a retrospective summary of it.
Where a plan was revised mid-sprint or a prompt produced something that
was later replaced, that shows here rather than being tidied away.

| File | What it is |
|------|------------|
| `HALI_IMPLEMENTATION_PLAN.md` | The initial build plan: schema, ingestion sources, service boundaries |
| `HALI_FINAL_SPRINT_PLAN.md` | The final-sprint scope decisions and cut list |
| `hali_final_sprint_prompt.md` | The as-run agent instruction for the final sprint |
| `hali_screenshot_capture_prompt.md` | The as-run agent instruction for the screenshot and demo capture pass |
